# DevOps Automation Scripts

A collection of production-ready Bash automation and monitoring scripts.

## Scripts Included

1. `backup.sh` - Automated archive utility that packages directories with timestamps and validates exit status.
2. `disk_monitor.sh` - Proactive disk usage monitoring script with configurable threshold alerting using `awk` and arithmetic checks.
3. `service_checker.sh` - Multi-target ping and reachability audit script with formatted terminal output.
4. `log_splitter.sh` - Demonstrates standard I/O streams and file descriptor redirection (`stdout` vs `stderr`).
5. `parse_services.sh` - Cloud service health monitor parsing nested JSON payloads using `jq`.
